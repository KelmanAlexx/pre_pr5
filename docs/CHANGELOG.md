# Changelog

Все заметные изменения проекта фиксируются в этом файле. Формат основан на Keep a Changelog. Версии используют семантическую нумерацию.

## [1.9.0] - 2026-10-31

### Added
- Добавлена таблица `Buildings` для хранения адреса здания.
- Добавлено поле `Dormitory.BuildingId` для связи общежития со зданием.
- Добавлены теги OpenTelemetry `jira.issue`, `campus.dormitory_id` и `campus.building_id`.
- Добавлен Sanity Test создания и удаления тестовой записи.
- Добавлена документация по обновлению и архитектурному решению.

### Fixed
- Исправлена организация хранения адреса: он отделён от основных данных общежития.

### Breaking Changes
- Удаление `Dormitory.Address` запланировано для отдельной Contract-фазы после полного перехода клиентов. В рамках безопасного Expand-релиза поле не удаляется.
