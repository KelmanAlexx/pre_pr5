# Branch Protection Rules для main

Для ветки `main` необходимо включить следующие ограничения:

1. Запретить прямой push для обычных разработчиков.
2. Все изменения вносить через Pull Request / Merge Request.
3. Требовать минимум **2 одобрения** от других участников команды.
4. Запретить объединение, пока не пройдены обязательные проверки CI:
   - восстановление NuGet-пакетов;
   - `dotnet build`;
   - `dotnet test`;
   - проверка SQL-скриптов на тестовой базе;
   - проверка форматирования и анализатора кода.
5. Запретить force push и удаление ветки `main`.
6. Требовать разрешения всех замечаний Review.
7. После изменения исходного кода повторно запускать CI.
8. Доступ к изменению правил защиты оставить администраторам репозитория.

В GitHub эти настройки находятся в Settings → Branches / Rulesets. В GitLab используются Settings → Repository → Protected branches и правила Merge Request.
